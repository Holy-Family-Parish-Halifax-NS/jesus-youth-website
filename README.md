# jesus-youth-website

Website for the Jesus Youth Family Prayer Group at Holy Family Syro-Malabar Catholic Parish, Halifax, NS.

**Status:** planning. The website has not been built yet.

- `CLAUDE.md`: the plan, style and rules for the site
- `content/`: finished text (9-month journey, family prayer in English and Malayalam)
- `assets/`: logos, poster and photos
- `events/`: one-time event pages, e.g. `events/rosary-2026/` (10-day Family Rosary sign-up)
